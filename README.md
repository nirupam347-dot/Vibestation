## ✦ VibeStation ✦

A real-time procedural lo-fi ambient audio generator and terminal waveform visualizer built with **Python**, **NumPy**, **Pygame**, and **Rich**.

## Features
* **Procedural Audio Synthesis:** Generates warm D minor 9 chords, subtle LFO tape warble, and vinyl crackle mathematically in real time using `numpy` and `pygame`—no external `.mp3` or `.wav` files required.
* **Live Terminal Visualizer:** Renders an animated terminal waveform, focus quotes, and a session timer using `rich`.
* **Zero-Friction Launcher:** Includes `run_station.bat` for one-click startup on Windows.
